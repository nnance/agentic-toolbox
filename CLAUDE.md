## Project Overview

The Agentic Toolbox is a TypeScript library that provides modular AI agent components for building custom workflows. The project is currently in early development with minimal implementation.

## Key Commands

- `npm run build` - Compile TypeScript to JavaScript in dist/
- `npm run dev` - Run in development mode with hot reload using nodemon and ts-node
- `npm start` - Run the compiled JavaScript from dist/
- `npm run clean` - Remove build artifacts from dist/
- `npm run prepublishOnly` - Clean and build for publishing

Note: Tests are not yet implemented (test script exits with error).

## Architecture

The project uses a standard TypeScript library structure:
- `/src/` - TypeScript source code (currently minimal - just console.log)
- `/dist/` - Compiled JavaScript output (generated by `npm run build`)
- Entry point: `src/index.ts` compiles to `dist/index.js`

TypeScript configuration:
- Target: ES2020
- Module: CommonJS
- Strict mode enabled
- Generates declaration files and source maps

## Development Requirements

- Node.js >= 16.0.0
- TypeScript compilation required for execution
- Uses nodemon for development hot reload with ts-node
